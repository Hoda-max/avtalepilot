1. What is AvtalePilot?

AvtalePilot is a contract and deadline management app for organizations. It gives a company one place to store contracts, see who is responsible, track important dates, and record decisions before deadlines pass.

It helps answer four everyday questions:

  1. Where is the contract?
  2. When must someone act?
  3. Who is responsible?
  4. What decision was made?

Short description: AvtalePilot helps organizations keep contracts, responsibilities, and deadlines under control in one place.

2. Who it is for

Businesses, municipalities, nonprofits, and other organizations — for example construction firms, IT companies, and property companies that need to track agreements, leases, and subscriptions.

6. Important concepts

  • Ansvarlig / Owner: the person responsible for a contract (must be a user in the organization).
  • Key dates: notice, renewal, and expiry — reminders are created automatically.
  • Decision: renew, renegotiate, or end — saved in history.
  • organization_id: every record belongs to an organization (MVP uses one; multi-org can come later).

7. How to run the app

  1. Open the project folder: Desktop\Avtalepilot
  2. Make sure .env.local has Supabase URL + anon key
  3. Run npm run dev
  4. Open http://localhost:3000

Database setup SQL files are in supabase/migrations. Optional demo data is in supabase/seed/001_sample_data.sql.

8. Current status

The practical MVP is working locally: login, one organization, suppliers, contracts with documents, dates, reminders, decisions, dashboard, and three interface languages. Next optional step: deploy online with Vercel.
